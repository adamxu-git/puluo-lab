# Security policy

[简体中文](#简体中文)

For issues involving credentials, isolation, browser egress, or audit data, use GitHub’s [private vulnerability report form](https://github.com/adamxu-git/puluo-lab-homeforai/security/advisories/new) when available. If private reporting is unavailable, open an issue asking for a private contact channel and share the details once that channel is established.

Include the affected revision, host and guest versions, VM mode, optional networking features in use, and the observed impact. Share sanitized supporting evidence and omit credentials and raw session logs.

## 简体中文

发现凭据、隔离、浏览器出站或审计数据相关的安全问题时，优先通过 [GitHub 私密漏洞报告](https://github.com/adamxu-git/puluo-lab-homeforai/security/advisories/new)联系维护者。如果表单不可用，请先开 Issue 询问私下联系渠道，随后通过该渠道提供细节。

请附上受影响的版本、宿主和来宾系统版本、VM 模式、已启用的可选网络功能，以及观察到的影响。提交证据前请脱敏，去除凭据和原始会话日志。
